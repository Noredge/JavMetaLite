JavMetaLite v{VERSION}
==================

[English]
1. Run JavMetaLite.exe; no installation is required.
2. Choose or drop one movie and verify the detected ID.
3. Search, choose a source for each field, and edit as needed.
4. Choose outputs and a destination, review the preview, then save.
Requires Windows 10/11 x64. The embedded browser requires Microsoft Edge WebView2 Runtime.
Keep backups of important media. If an online source is unavailable, switch sources or enter data manually.

[简体中文]
1. 运行 JavMetaLite.exe；无需安装。
2. 选择或拖入一个影片，检查识别出的番号。
3. 搜索资料，逐项选择来源并按需修改。
4. 选择输出与目标位置，检查保存前预览后执行。
要求：Windows 10/11 x64；内置浏览器需要 Microsoft Edge WebView2 Runtime。
提示：请先保留重要影片的备份；在线来源不可用时可切换来源或手动填写。

[繁體中文]
1. 執行 JavMetaLite.exe；不需要安裝。
2. 選擇或拖入一個影片，檢查辨識出的番號。
3. 搜尋資料，逐項選擇來源並按需修改。
4. 選擇輸出與目標位置，檢查儲存前預覽後執行。
需求：Windows 10/11 x64；內建瀏覽器需要 Microsoft Edge WebView2 Runtime。
提示：請先備份重要影片；線上來源無法使用時可切換來源或手動填寫。

[日本語]
1. JavMetaLite.exe を実行します。インストールは不要です。
2. 動画を選択またはドロップし、検出された品番を確認します。
3. 情報を検索し、項目ごとに取得元を選択して必要に応じて編集します。
4. 出力内容と保存先を選択し、保存前プレビューを確認して実行します。
動作環境：Windows 10/11 x64。内蔵ブラウザーには Microsoft Edge WebView2 Runtime が必要です。
重要な動画は事前にバックアップしてください。取得元が利用できない場合は別の取得元または手動入力を使用できます。
