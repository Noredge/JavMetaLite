# JavMetaLite v1.2.0-preview.19 R18.dev 网页路由修正

状态：已实现，待用户体验验收

基线：`v1.2.0-preview.18`，`483d9d0`

更新日期：2026-09-03

## 问题

- 番号不能可靠推导出 R18.dev/DMM 的内部 `content_id`。例如 `FNS-121` 的真实值是 `1fns121`，通用补零规则却会猜成 `fns00121`。
- R18.dev 的自定义“页面不存在”有时返回 HTTP 200，preview.18 因而把它误判为网站维护。

## 已实现规则

- 自动搜索已经取得 R18.dev 结果及真实 `content_id`：网页查询直接打开对应的人类可读详情页。
- 没有可信 `content_id`：不再拼接猜测地址，改为打开官网首页并预填原番号，等待用户提交或修改。
- 页面正文包含 R18.dev 的“Sorry, this page does not exist”标记时，即使 HTTP 状态为 200，也按“可能尚未收录”处理并返回预填搜索。
- HTTP 4xx/5xx、导航失败、Cloudflare/维护页等没有正常站点结构的页面仍归为“暂时无法访问”。
- 自动元数据搜索逻辑保持不变，仍会通过 `dvd_id` 查询发现真实 `content_id`。

## 验收门槛

- Core 回归覆盖有/无真实 `content_id` 的网页路由、HTTP 404、HTTP 200 自定义缺失页及服务器异常优先级。
- WPF 回归继续覆盖未收录/不可用提示和详情页读取门禁。
- 完整自动化门禁通过后生成 `v1.2.0-preview.19` 便携体验包并提交本地 Git，不推送远端。
