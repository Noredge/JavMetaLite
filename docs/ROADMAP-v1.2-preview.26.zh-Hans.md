# JavMetaLite v1.2.0-preview.26 图片查看与来源反馈

状态：已实现，待用户体验验收

基线：`v1.2.0-preview.25`，`c5ca3a5`

更新日期：2026-09-03

## 本轮目标

在不增加逐片确认步骤的前提下，让用户更容易看清图片、判断搜索结果，并只修复真正失败的资料来源。

## 已实现方案

- 海报裁切与完整封套 / fanart 支持单击放大。
- 图片查看器支持按钮和键盘左右切换，`Esc` 关闭；只呈现当前已经安全载入的图片。
- 图片区明确区分四种状态：尚未选择影片、正在载入、没有可用图片、图片已载入。
- 搜索工具栏下方增加来源结果条，逐项显示来源名称、成功或失败、可用字段数、耗时与失败详情。
- 多来源部分失败时显示“重试失败来源”，重试会保留成功结果，只请求上次失败的来源。
- 队列搜索状态改为轻量彩色状态块；它只提供信息，不要求用户逐片标记或确认。
- 单来源完全失败仍可直接使用原“搜索资料”重新搜索；仅在存在明确的逐来源失败记录时显示定向重试。

## 交互边界

- 本轮查看器覆盖主界面已经载入的海报与 fanart；样品图仍由保存选项和 `extrafanart` 输出逻辑管理。
- 重试不覆盖用户已经做出的字段来源选择；成功返回后仍进入原有可审核状态。
- 搜索反馈不会常驻占用空间：尚未搜索或没有可说明的结果时自动收起。
- 队列状态不改变“一键保存全部”的产品方向。

## 验收重点

1. 单击海报或 fanart 能打开大图，左右键可切换，`Esc` 可关闭。
2. 切换影片后不会短暂显示上一部影片的图片。
3. 多来源一成一败时，结果条应同时显示成功来源和失败来源。
4. 单击“重试失败来源”后，已成功来源不应再次请求。
5. 最小窗口与批量模式下，结果条不应使搜索工具栏换成第三行或遮挡保存区。
6. 队列状态清晰可辨，但不新增逐片确认动作。
