# JavMetaLite v1.2.0-preview.24 队列对齐与紧凑来源栏

状态：已实现，待用户体验验收

基线：`v1.2.0-preview.23`，`6473c10`

更新日期：2026-09-03

## 本轮目标

修正 preview.23 的两处视觉回退：左侧队列操作按钮宽度与列线不一致，以及自动资料来源单独占用第二行。保持搜索、手动网页查询、来源记忆和保存行为不变。

## 已实现

- 队列的“全选 / 取消全选 / 移除所选 / 清空队列”改成等宽两列，行列边缘统一。
- 自动来源选择器回到番号、搜索资料和手动网页查询所在的主工具栏；常用窗口宽度下保持单行，空间不足时整组换行。
- 可见标签缩短为“自动来源”，避免与独立的“手动网页查询”混淆。
- 当前自动搜索策略仍随“记住当前设置”保存；手动网页查询仍可每次独立选择网站。
- 原本占据第二行的策略说明改为来源下拉框提示；自定义多来源时继续显示“编辑规则”。
- 新增简体中文、繁体中文、英语和日语资源，以及队列按钮等宽对齐、来源栏同行与策略提示的 WPF 回归检查。

## 验收重点

1. 批量模式下确认四个队列操作按钮形成整齐的两行两列。
2. 在普通窗口宽度下确认番号、搜索资料、手动网页查询和自动来源位于同一行。
3. 将窗口缩至最小宽度，确认自动来源整组换行且没有控件越界。
4. 切换自动来源，确认下拉框提示随模式更新；手动网页查询入口及行为不随之改变。
5. 选择“自定义多来源”，确认“编辑规则”仍可用。
