# JavMetaLite v1.2.0-preview.29 深色图片选择与缩略图胶片栏

状态：已实现，待用户体验验收

基线：`v1.2.0-preview.28`，`32ae247`

更新日期：2026-09-03

## 目标

修复图片类型选择框与深色界面不一致的问题，并让多张图片的浏览与选择更接近 Windows Photos：所有候选在底部保持可见，用户不必依赖上一张、下一张逐张寻找。

## 已实现方案

- 图片类型选择框采用完整深色模板，包括关闭状态、下拉列表、选中项与悬停状态。
- 主图片下方增加横向缩略图胶片栏，并随“全部 / 海报 / Fanart / Extra Fanart”筛选结果同步变化。
- 点击缩略图直接切换主图片；当前项使用蓝色描边，并在键盘或按钮切换时自动滚入可视区域。
- Extra Fanart 缩略图右上角提供选择框，可直接保留或取消本地及在线剧照。
- 缩略图选择框、主图上方选择框、全选、取消全选和最终应用结果保持同步。
- 鼠标滚轮在胶片栏内执行横向像素滚动，兼容高精度滚轮输入。
- 后台预载完成后直接更新对应缩略图，不重复下载或解码同一图片。

## 验收重点

1. 图片类型选择框及展开菜单均为深色，文字清晰可读。
2. 底部显示当前类型的全部缩略图，数量与上方筛选计数一致。
3. 点击任意缩略图会切换主图，蓝色当前项描边同步移动。
4. Extra Fanart 可直接在缩略图上勾选，顶部选择状态和总数立即同步。
5. 左右键及上一张、下一张仍可使用，当前缩略图会自动保持可见。
6. 大量图片时可在胶片栏上用滚轮自然地横向滚动。

- 生成 `v1.2.0-preview.29` win-x64 便携体验包并核对版本与 SHA-256。
