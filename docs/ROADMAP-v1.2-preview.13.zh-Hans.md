# JavMetaLite v1.2.0-preview.13 智能导入路线图

状态：已完成，待用户体验验收

基线：`v1.2.0-preview.12`，`1f2eae3`

更新日期：2026-09-03

## 一、目标

将“选择视频”“拖放”和“扫描文件夹”统一为可预测的影片导入体验，不再要求文件夹预先符合严格的番号目录结构。

> 单片入口接收一个逻辑影片；批量入口接收任意文件与文件夹集合。发现阶段默认全选结果，用户只需排除不需要的项目。

## 二、统一输入规则

- 单个受支持视频直接加入当前工作区。
- 只包含一个逻辑影片的文件夹直接加入；嵌套目录和 `CD1/CD2` 分段同样适用。
- 包含多部逻辑影片的文件夹自动进入批量导入预览。
- 同时拖入多个视频、多个文件夹或文件与文件夹的组合时，统一递归发现、去重并按影片分组。
- “扫描文件夹”默认包含子文件夹，用户仍可关闭递归扫描。
- 已有的标准番号文件夹保持快速兼容路径，但不再是文件夹导入的必要条件。

## 三、逻辑影片预览

发现预览从物理文件列表改为逻辑影片列表：

- 显示检测到的番号或原文件主名称；
- 显示主视频路径；
- 将同一影片的 `CD1/CD2` 显示为一个项目和分段数量；
- 标明“可加入”“番号待确认”或“已在队列”；
- 可加入项目默认全选，并提供全选与取消全选；
- 已在队列的完整重复项显示但不可重复选择。

确认导入只把选中的逻辑影片加入内存队列，不自动搜索、移动影片或写入 NFO/图片。

## 四、安全与性能

- 发现过程异步、可取消且只读。
- 不跟随目录连接、符号链接等重解析点，避免循环扫描和越界发现。
- 无权限或临时不可用目录只记录诊断，不阻断其他结果。
- 重叠输入路径、重复文件和已经在队列中的影片统一去重。
- 结果顺序稳定；队列继续复用现有 `MovieFileSet` CD 分组和 `MovieJob` 隔离模型。

## 五、实施阶段

### R1：Core 统一发现

- 新增多路径输入发现服务，同时接收文件和文件夹。
- 支持可选递归、重叠路径去重、诊断和取消。
- 输出 `MovieFileSet` 逻辑影片，而不是未分组的文件路径。

### R2：智能拖放路由

- 放宽拖放限制，接收多个文件夹和混合输入。
- 一个逻辑影片直接加入；多个逻辑影片自动打开批量预览。
- 复用现有加入队列、CD 合并、本地 NFO/图片读取与保存设置初始化流程。

### R3：分组发现界面

- 默认递归和默认全选。
- 显示番号、路径、分段数、重复与待确认状态。
- 增加全选和取消全选，并继续展示不可读目录诊断。

### R4：质量与交付

- 补充混合路径、嵌套目录、CD 分组、重复输入、缺失路径和非递归测试。
- UI smoke 覆盖默认递归、逻辑分组、默认选择、重复项与单影片直接导入。
- 更新四语言资源、README、CHANGELOG 与测试说明。
- 运行完整自动化门禁，生成 preview.13 便携包和 SHA-256，并提交本地 Git。

## 六、完成标准

- 用户可拖入普通文件夹、媒体库子树、多个文件夹或混合文件与文件夹。
- 一个逻辑影片不会被迫进入批量确认；多个影片不会再因“文件夹内有多个视频”报错。
- 多 CD 在预览和队列中都只占一个逻辑项目。
- 递归扫描默认启用但可关闭，且扫描可取消、只读、不跟随重解析点。
- 导入项目默认全选；用户无需逐片确认，只需取消例外项目。
- 重复、无番号和不可读目录均有清晰状态，不会静默丢失。
- 原有单片/批量编辑、搜索、保存预览和文件安全机制没有回退。
