# JavMetaLite v1.2.0-preview.42 图片来源比较与全局定位

## 本轮目标

- 统一主界面三个图片入口的查看器行为，不再根据入口自动缩小到单一图片类型。
- 将所有可用封套来源放入同一个查看器中，支持逐张比较并直接采用来源。

## 全部图片定位

- “查看图片”、海报裁切和完整封套入口都默认选择“全部图片”。
- 海报裁切入口仍显示当前海报，但位置改为其在全部候选中的真实序号。
- 完整封套入口同样显示当前横版封套及全局序号。
- “查看图片”默认从当前封套来源的海报开始；若没有海报，则依次回退到当前完整封套和第一张可用图片。
- 用户手动切换图片类型后，位置与总数才按筛选结果重新计算。

## 封套来源比较

- 每个封套来源向查看器提供一张海报裁切和一张完整封套；本地成对旁车缺少其中一项时只显示实际存在的图片。
- 图片标题同时显示角色与来源，便于在本地图片、手动封套、LibreDMM 和 R18.dev 之间比较。
- 查看器顶部使用与主界面一致的“来源”下拉菜单，明确列出本地图片、手动封套、LibreDMM、R18.dev 等现有来源，并用勾号标出当前来源。
- 切换来源后查看器保持打开；若当前正在看海报、fanart 或在线样品图，则直接跳到新来源的同类型图片，便于原位比较。
- 本地图片栏始终保留；在线候选栏只显示当前来源的海报、fanart 与 Extra Fanart，“全部图片”的数量、序号和方向键导航同步按当前来源重算。
- 首次切换到在线来源时默认全选该来源的 Extra Fanart；用户手动调整后，查看器会分别记住各来源的临时选择，最终只提交当前来源的样品图。
- 没有在线候选的本地或手动来源显示明确空状态，不自动混入或回退到其他在线来源。
- 来源与在线样品图改为暂存修改；点击“应用图片设置”后统一提交，关闭或 Esc 放弃未应用修改。已确认的本地图片删除仍立即执行。
- 底部不再显示容易与图片浏览混淆的“使用此封套来源 / 当前封套来源”按钮。
- 应用来源后仍保持 poster 与 fanart 的统一来源规则；Extra Fanart 的人工选择保持独立。
- 同一来源存在多个封套地址时按顺序尝试回退；海报裁切与完整封套复用有限内存缓存中的原图，避免重复下载。

## 现有行为边界

- 图片列表仍默认收起，本地图片与在线候选继续分行显示。
- 本地图片删除仍必须经过深色强制确认；手动选择的外部完整封套只用于比较，不提供直接删除入口。
- 在线 Extra Fanart 仍可逐张勾选、全选或取消全选，但操作范围仅限当前来源。
- 选择图片类型、上一张、下一张及方向键导航保持原有行为。

## 验证门槛

- WPF 测试覆盖查看器默认“全部图片”、来源过滤后的全局序号、顶部来源菜单、同类型跳转、来源内选择记忆，以及应用/关闭边界。
- 主窗口集成测试分别从“查看图片”、海报裁切与完整封套进入，验证三者定位到同一完整候选集合中的正确项目。
- 完整自动化门槛继续覆盖 Core、文件事务和 WPF UI。
