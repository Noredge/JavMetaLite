# JavMetaLite v1.2.0-preview.17 网页查询与 R18.dev 正常页面路线

状态：已实现，待用户体验验收

基线：`v1.2.0-preview.16`，`e690e08`

更新日期：2026-09-03

## 目标

把手动网站操作与自动“多来源搜索”清楚区分，并确保 R18.dev 浏览器只向用户展示正常影片页面。

## 已实现规则

- 主动作命名为“网页查询”；来源已确定时显示“网页查询 · 来源”，需要选择时显示下拉箭头。
- 多来源菜单使用“使用 LibreDMM / R18.dev / JAVLibrary 查询”，不再以含义相近的“来源网页”与右侧来源策略并列。
- 单来源、自动单一成功来源和多来源菜单的决策规则保持不变。
- R18.dev 打开官方正常详情页 `…/detail/-/id=<content_id>/`，不在浏览器中显示 `/json` 原始数据。
- 用户在可读详情页点击“读取当前影片”后，程序才把页面转换为对应 `combined=<content_id>/json` 地址并在后台读取。
- 既有 R18.dev 搜索结果中的 JSON 地址或 `content_id` 会自动转换为正常影片页；相似恶意域名、404、非详情页和原始 JSON 页均不可导入。

## 候选与覆盖规则

- 网页查询结果仍只加入当前影片候选，并只自动填充空白字段。
- 已选择字段、手动修改值和封套来源保持不变。
- 后台 JSON 解析后仍执行影片番号一致性检查，避免把其他页面资料加入当前影片。

## 验收门槛

- Core 回归覆盖正常页面路由、旧 JSON 地址转换、准确后台 API 地址、解析结果与不可信页面拒绝。
- WPF 回归覆盖四语言资源一致性、英文动态按钮/菜单、R18.dev 正常页面地址和来源专属浏览器说明。
- 完整自动化门禁通过后生成 `v1.2.0-preview.17` 便携体验包并提交本地 Git，不推送远端。
