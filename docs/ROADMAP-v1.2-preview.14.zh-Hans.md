# JavMetaLite v1.2.0-preview.14 易用性收尾路线

状态：已完成，待用户体验验收

基线：`v1.2.0-preview.13`，`e888bba`

更新日期：2026-09-03

## 一、输入路径可读性

- 发现窗口顶部保留全部文件与文件夹输入路径。
- 多路径区域设置独立最大高度与纵向滚动条，使用像素滚动，不再裁掉后续路径。
- 影片发现结果列表继续保持自己的滚动区域，两者互不抢占窗口空间。

## 二、统一保存预览选项

- 单片模式与批量模式只显示一个“跳过保存预览”选项，切换入口时不再出现第二个近义开关。
- 关闭时保持原有默认：每次保存先显示实际文件变更。
- 开启时，仅无问题、无覆盖冲突的干净计划可以直接执行。
- 已有 NFO/图片、问题项目或覆盖冲突仍强制显示安全预览，并要求用户明确确认覆盖。
- 目标影片冲突始终阻止执行；跳过预览不会获得静默覆盖影片或旁车的权限。

## 三、偏好兼容

- 偏好升级至 schema v10，使用一个 `SkipSavePreview` 字段。
- 旧配置的 `DirectSaveOverwrite` 或 `SkipBatchSavePreview` 任一为真时，迁移为新统一选项。
- 旧字段迁移后不再写回设置文件；未开启“记住保存偏好”时仍恢复安全默认关闭。

## 四、完成标准

- 多路径超过显示高度后可使用鼠标滚轮连续查看。
- 单片和批量入口显示同一个选项及同一选中状态。
- 干净单片和干净批次都可跳过预览。
- 单片覆盖冲突、批量覆盖冲突和批量问题项均不能绕过安全预览。
- 四语言资源、偏好迁移、核心测试、文件事务测试与 WPF UI 门禁全部通过。
