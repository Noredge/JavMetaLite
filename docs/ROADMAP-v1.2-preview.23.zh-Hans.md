# JavMetaLite v1.2.0-preview.23 审核工作台 UI 重构

状态：已实现，待用户体验验收

基线：`v1.2.0-preview.22`，`c7aaabd`

更新日期：2026-09-03

## 本轮目标

在不改变搜刮、NFO、图片和安全保存规则的前提下，按已确认的界面原型重新组织审核工作台，让用户优先看影片资料，明确区分自动搜索、手动网页查询、当前影片和批量勾选。

## 已实现

- 搜索区拆成两层：第一层为番号、搜索资料和独立的手动网页查询；第二层明确标注“自动资料来源”，并显示当前策略摘要。
- 自定义多来源的“编辑规则”只在该模式出现，不再形成含义不明的孤立按钮。
- 只有切换到另一部影片时，资料区才回到标题顶部；编辑字段、切换候选或更新当前影片不会打断阅读位置。
- 队列蓝色选中行表示“正在查看”，复选框继续只表示是否参与下一次批量搜索和保存；移除类似播放入口的三角符号。
- 上一部、下一部使用可见文字，并保留原有快捷键和提示。
- 图片区改称“图片预览”，分别标注“海报裁切”和“完整封套 / fanart”，尺寸信息紧邻完整封套。
- 字段来源按钮提升至 11px 和至少 24px 点击高度，继续使用原有候选菜单及来源颜色。
- 输出、命名和保存行为默认折叠为实时摘要；目标位置和主保存按钮始终可见。
- 单片与批量模式共用同一个“跳过保存预览”和“记住当前设置”入口。
- 队列与图片区支持拖动调整宽度；批量模式不再强制把窗口扩展到 1230px，最小宽度保持 930px。
- 保留深色下拉框、队列像素滚动、动态“保存全部 / 保存所选”、完成后移出队列和现有安全预览规则。

## 验收重点

1. 在单片与批量模式间切换，确认搜索区层级一致、手动网页查询不随自动来源变化。
2. 将资料区滚到底部后切换队列影片，确认新影片从标题开始显示；修改同一影片字段时不应跳回顶部。
3. 勾选和取消队列复选框，确认蓝色“正在查看”行不随批量勾选改变。
4. 展开、收起保存设置，确认摘要随 NFO、图片、标题番号和跳过预览选项实时变化。
5. 将窗口缩到 930–1000px，并拖动两处分隔线，确认主要控件可用且窗口不被强制放大。
6. 切换简体中文、繁体中文、英语和日语，确认新增标签与摘要完整显示。
