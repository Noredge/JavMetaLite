## 行为

- 普通单片优先读取影片同名 NFO 和图片；缺失时，在只有一部逻辑影片的目录里回退读取 `movie.nfo`、`poster`、`fanart` 图片，大小写不敏感。
- 多部不同影片混放时，不关联目录级 NFO 和封套。CD 分段仍按同一逻辑影片识别，原有输出规则不变。
- 普通单片原地保存保留已载入的目录级文件命名；保存到新目录沿用现有输出命名。判断依据是最终解析出的目标目录，而不是界面选项名称。
- 同名格式与目录级格式共存时，沿用读取优先级，只更新选中的文件，不合并或删除另一份 NFO。
- 明确要求重命名影片时，同名格式的配套文件仍随影片改名；`movie.nfo` 等目录级名称不随影片改名。
- 缺失输出按已识别的格式补齐；NFO 中显式的 `num` 与 `cid` 保持番号与内容 ID 的区别。
- PNG 原地替换保持 PNG 编码。WebP 可以保留或迁移；当前没有 WebP 编码器，原地替换会阻止保存并提示，避免扩展名与内容不符。
