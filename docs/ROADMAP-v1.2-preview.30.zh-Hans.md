# JavMetaLite v1.2.0-preview.30 自适应图片预览与本地删除确认

状态：已实现，待用户体验验收

基线：`v1.2.0-preview.29`，`0651f97`

更新日期：2026-09-03

## 目标

让竖图、方图和横图在查看器中保留各自的视觉比例，并明确显示实际分辨率；同时为本地 Extra Fanart 提供可理解、可撤回且必须确认的删除入口。

## 已实现方案

- 主图片继续使用完整比例预览，并在右下角显示 `宽 × 高` 像素尺寸。
- 底部胶片栏从统一裁切改为完整显示；缩略图宽度随宽高比变化，竖图更窄、横图更宽。
- 本地图片的选择说明改为“保留这张本地图片”，与在线图片的“保存这张样品图”区分。
- 查看本地 Extra Fanart 时显示红色“删除本地图片”按钮。
- 点击删除按钮、取消本地图片勾选或批量取消全选时，均必须经过警告确认；选择“否”会恢复原状态。
- 确认只产生待删除计划，不会在查看器中立即操作文件。用户仍需点击“应用选择”并保存影片。
- 待删除路径保存在当前影片工作上下文中，重新搜刮资料不会把它静默恢复为选中。
- 保存时即使关闭 Extra Fanart 输出，也只删除明确确认过的本地图片；其余本地图片继续原样保留。

## 安全边界

1. 删除入口仅对已确认属于当前影片 `extrafanart/` 的本地图片显示。
2. 所有单张和批量删除意图必须经过确认，不允许通过普通取消选择绕过。
3. 关闭查看器或按 `Esc` 会丢弃未应用的删除意图。
4. 实际删除继续进入保存计划，并接受来源指纹检查、备份和失败回滚保护。
5. 待删除文件若仍在保存选择中，保存计划直接拒绝执行，避免删除后又被重新生成。

## 验收重点

1. 竖图与横图在主预览和缩略图中都不应被裁掉关键区域。
2. 切换图片时，右下角分辨率随当前图片准确更新。
3. 在线图片不显示本地删除按钮；本地 Extra Fanart 显示。
4. 拒绝删除确认后，顶部与缩略图勾选状态都应恢复。
5. 确认删除后，界面显示待删除状态，但文件在保存前仍然存在。
6. 未跳过保存预览时应显示移除项；取消保存保持文件，确认保存才执行删除。
