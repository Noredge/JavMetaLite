# JavMetaLite v1.2.0-preview.38 内嵌来源规则入口

## 本轮目标

- 让自动搜索来源的选择不再改变搜索栏结构。
- 保持普通来源与自定义多来源在相同窗口宽度下使用完全相同的行列布局。
- 将“编辑规则”收进来源选择框，减少额外按钮造成的视觉噪声。

## 交互设计

- 来源选择框右侧保留原有下拉箭头。
- 选择“自定义多来源”时，在箭头左侧显示紧凑齿轮，中间以淡色竖线分隔。
- 点击齿轮打开现有自定义字段来源规则窗口；点击选择框其余区域仍打开来源列表。
- 使用其他来源时隐藏齿轮和分隔线，但不改变来源选择框的外部尺寸或位置。
- 齿轮继续提供本地化提示，并暴露本地化的可访问名称。

## 响应式规则

- 搜索栏是否进入紧凑布局只由可用宽度决定，不再由当前来源决定。
- 单片最小窗口在空间允许时保持一行。
- 批量最小窗口继续使用已确定的两行结构，但切换来源不会重新分配行列。

## 验证门槛

- 四种界面语言下，来源名称、齿轮提示和可访问名称均正确。
- 单片及批量模式切换到自定义来源后，来源控件的行、列、跨度、宽度与坐标保持不变。
- 所有控件在最小窗口中不越界，完整自动化测试与发布包验证通过后提交本地 Git。
