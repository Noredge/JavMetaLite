# JavMetaLite v1.2.0-preview.22 当前设置记忆

状态：已实现，待用户体验验收

基线：`v1.2.0-preview.21`，`57c7839`

更新日期：2026-09-03

## 目标

消除“已经启用偏好记忆，但重新启动后搜索来源仍回到默认值”的体验断层，并为后续整体 UI 重排建立清晰的设置边界。

## 已实现规则

- 界面将“记住保存偏好”改为“记住当前设置”，提示中明确列出搜索来源、输出、目标位置、预览和跨盘校验。
- 开启后保存并恢复多来源、LibreDMM、R18.dev、JAVLibrary、自定义多来源和仅手动填写六种搜索模式。
- 关闭记忆时不保留上次搜索模式，下次启动安全回到“多来源搜索（推荐）”。
- 自定义字段与封套来源规则属于用户配置，继续独立保留；是否进入自定义搜索模式由当前设置记忆决定。
- schema v10 及更早版本因没有保存过搜索模式，迁移后采用推荐的多来源模式；无效值同样回退，不阻止程序启动。

## 验收门槛

- Core 回归覆盖六种模式、旧版迁移、无效值、关闭记忆和自定义规则独立保留。
- WPF 回归覆盖简体中文名称、完整提示和来源下拉框实际恢复。
- 完整自动化门禁通过后生成 `v1.2.0-preview.22` 便携体验包并提交本地 Git，不推送远端。
