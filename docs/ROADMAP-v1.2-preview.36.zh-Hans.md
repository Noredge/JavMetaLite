# JavMetaLite v1.2.0-preview.36 等尺寸折叠箭头

## 本轮目标

- 展开与收起不再使用两枚尺寸不一致的文字字符。
- 使用同一枚矢量箭头旋转 90° 表示状态，确保几何尺寸、线宽和圆角一致。
- 图片列表与保存设置继续共用同一套折叠视觉。
- 进一步提高未选中缩略图选择框的透明度，降低对图片的遮挡。

## 视觉参数

- 收起箭头：矢量箭头朝右。
- 展开箭头：同一矢量箭头顺时针旋转 90°。
- 未选中选择框：深色底约 40% 不透明，边框同步弱化。
- 悬停与选中状态保持较高不透明度，以维持操作反馈和辨识度。

## 验证门槛

- WPF 回归确认两个状态使用同一矢量对象、旋转角度正确且布局尺寸不变。
- 回归确认未选中选择框的不透明度低于上一预览版，同时仍有可见边界。
- 完整自动化测试、发布打包与包内版本验证通过后提交本地 Git。
