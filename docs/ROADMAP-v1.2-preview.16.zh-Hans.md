# JavMetaLite v1.2.0-preview.16 来源感知网页导入路线

状态：已实现，待用户体验验收

基线：`v1.2.0-preview.15`，`087b2c8`

更新日期：2026-09-03

## 目标

让“网页导入”与右侧来源选择保持一致，同时避免多来源模式暗中指定一个并不存在的主来源。

## 已实现规则

- LibreDMM、R18.dev、JAVLibrary 单来源模式直接打开对应网站。
- “仅手动填写”继续直达 JAVLibrary，保留原有验证后导入流程。
- 自动多来源搜索只有一个成功来源时直接打开该来源。
- 自动模式没有结果、存在多个成功来源，或者使用自定义多来源时，显示三个来源的深色菜单。
- 菜单说明该来源当前被多少个字段或封套采用，并优先使用搜索结果返回的准确来源地址。
- 浏览器校验所选来源的可信域名与详情页结构，LibreDMM、R18.dev、JAVLibrary 分别交给匹配的导入器。

## 候选与覆盖规则

- 网页导入结果加入当前影片的来源候选。
- 只自动补充当前为空的字段。
- 保留已经选择或手动修改的字段值与封套来源。
- 导入页面番号与当前影片不一致时拒绝加入，避免跨影片污染。

## 验收门槛

- Core 回归覆盖来源决策、准确 URL、恶意相似域名拒绝、详情页识别及候选合并。
- WPF 回归覆盖动态按钮、三来源深色菜单、最小窗口布局和按来源显示的浏览器说明。
- 完整自动化门禁通过后生成 `v1.2.0-preview.16` 便携体验包。
