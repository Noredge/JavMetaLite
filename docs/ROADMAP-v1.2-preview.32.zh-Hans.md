# JavMetaLite v1.2.0-preview.32 本地图片直接管理

## 目标

让图片查看器中的本地图片操作与实际结果一致：本地图片只提供查看与删除，在线 Extra Fanart 继续负责选择要保存的候选；需要重建整套剧照时，另由明确的保存选项控制。

## 本轮范围

- 本地海报、横版 Fanart 与 Extra Fanart 不再显示勾选框、全选、取消全选或应用语义。
- 查看本地图片时显示“删除本地图片”，每次删除都必须经过警告确认；确认后立即删除磁盘文件并从胶片栏移除。
- 删除失败时保留当前项目并显示错误，不把失败操作伪装成成功。
- 在线 Extra Fanart 保留逐张选择、全选、取消全选与应用选择。
- 增加默认关闭的“替换本地 Extra Fanart”：启用后保存会移除整套现有本地 `extrafanart/`，只写入当前选择的在线图片；未选择在线图片时清空该目录中的现有图片。
- 移除资料区内重复的分来源搜索结果面板，搜索结果继续由窗口底部状态栏提示；存在可重试的失败来源时，在底栏显示紧凑的重试按钮。
- 保存偏好升级到 schema 12，并记忆新的替换选项。

## 安全边界

1. “替换本地 Extra Fanart”默认关闭，且只在启用 Extra Fanart 输出时可选。
2. 关闭 Extra Fanart 输出会自动关闭替换选项。
3. 单张本地图片删除必须逐次确认，不支持无确认批量删除。
4. 替换模式仍通过现有保存预览、冲突检测、备份与事务提交链路执行。
5. 普通保存模式继续保留未删除的本地 Extra Fanart。

## 验收

1. 本地海报、Fanart 与 Extra Fanart 均能在查看器内确认后直接删除。
2. 本地图片不显示选择/应用控件；在线 Extra Fanart 的选择行为不变。
3. 替换模式只写入在线所选图片，并能以零选择清空现有本地 Extra Fanart。
4. 上方分来源结果面板不再出现，底部状态栏仍能显示操作结果和按需出现的失败来源重试入口。
5. 完整自动化测试与 WPF UI 冒烟测试通过。
