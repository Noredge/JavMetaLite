# JavMetaLite v1.2.0-preview.35 统一折叠入口

## 本轮目标

- 图片查看器的图片列表默认收起，让主图获得更多垂直空间。
- 折叠标题直接显示当前筛选下的本地图片与在线候选数量。
- 展开状态只保留在当前查看器会话，不写入用户设置。
- 保存设置改为“左侧箭头 + 标题 + 摘要”，移除最右侧孤立箭头和装饰方块。
- 两个区域均允许点击整条标题栏展开或收起。

## 交互规则

1. 收起图片列表不会影响上一张、下一张或左右方向键导航。
2. 切换全部、海报、Fanart、Extra Fanart 时保留当前查看器内的展开状态，并同步刷新数量摘要。
3. 折叠箭头在收起时朝右、展开时朝下；常态使用弱化色，悬停和键盘聚焦时使用强调色。
4. 保存设置继续显示输出数量、标题番号和预览方式摘要，原有选项及保存逻辑不变。

## 验证门槛

- WPF 回归覆盖图片列表默认收起、展开、数量摘要，以及保存设置箭头的位置、方向和共用样式。
- 完整自动化测试、发布打包与包内版本验证通过后提交本地 Git。
