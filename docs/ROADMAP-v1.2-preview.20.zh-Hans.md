# JavMetaLite v1.2.0-preview.20 独立手动网页查询

状态：已实现，待用户体验验收

基线：`v1.2.0-preview.19`，`68d7e7f`

更新日期：2026-09-03

## 目标

将自动资料搜索与浏览器辅助查询彻底解耦，避免两个相邻入口互相改变含义或行为。

## 已实现规则

- 左侧入口统一命名为“手动网页查询 ▾”，明确它会打开网站并由用户确认页面。
- 右侧来源框只决定自动“搜索资料”的策略，不再决定网页查询打开哪个网站。
- 每次点击“手动网页查询”都显示 LibreDMM、R18.dev、JAVLibrary 三个选项，用户可随时改选。
- 单来源、多来源、自定义多来源及仅手动填写模式下，按钮标签、提示和网站菜单保持一致。
- 网页导入仍只作为候选补充，不覆盖当前审核选择；各网站的详情页验证及 R18.dev 安全回退规则保持不变。

## 验收门槛

- 删除旧的自动来源到网页来源映射逻辑，避免后续重新耦合。
- WPF 回归验证右侧选择 LibreDMM 或仅手动填写时，左侧仍显示统一名称并提供全部三个网站。
- 完整自动化门禁通过后生成 `v1.2.0-preview.20` 便携体验包并提交本地 Git，不推送远端。
