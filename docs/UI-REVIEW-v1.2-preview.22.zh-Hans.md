# JavMetaLite 整体 UI 审视与优化建议

审视版本：`v1.2.0-preview.22`

更新日期：2026-09-03

历史说明（2026-09-04）：下文保留当时的审视结论，不作为当前待办。必要键盘交互已在 preview.40 完成，图片与来源交互已在 preview.42 完成；当前收尾与发布限制见 [preview.43 收尾记录](CLOSEOUT-v1.2.0-preview.43.zh-Hans.md)。

进度更新：preview.23–preview.26 已完成滚动复位、搜索区响应式重排、队列焦点区分、保存设置折叠、图片标签与放大查看、可调栏宽，以及加载/无图/来源失败状态反馈。当前明确保留的后续项是可发现的键盘快捷键与发布候选体验验证。

## 总体判断

现有深色视觉体系、主色和三栏工作台已经形成稳定产品辨识度，下一阶段不需要重做主题。主要问题来自信息层级、固定尺寸和状态表达：审核资料的可视面积被上下工具区压缩，切换影片会沿用共享滚动位置，自定义来源配置形成孤立的第二行，批量队列的“正在查看”与“参与批处理”缺少清晰区分。

## 第一优先级：直接影响审核流程

1. 为资料区 ScrollViewer 设置明确名称；切换到另一部影片时回到顶部，让标题、原标题等首要字段始终先出现。切换来源候选或编辑当前影片时不应意外复位。
2. 将搜索区重排为语义明确的两行：第一行放番号、搜索资料和手动网页查询；第二行增加“自动资料来源”标签，放来源选择与仅在自定义模式出现的“编辑规则”。单片与批量模式使用同一结构。
3. 区分队列焦点和批处理勾选：蓝色行只表达“正在查看”，复选框表达“参与搜索/保存”；将类似播放按钮的三角图形换成查看/影片图标，并为上一部、下一部提供文字或明确提示。

## 第二优先级：释放空间并提升可读性

1. 将底部设置分成“生成内容”“命名整理”“保存行为”和“目标位置”。默认展示常用摘要，把跨盘校验、记住当前设置等低频项放入可展开的更多设置区域，使 metadata 视口获得更多高度。
2. 将“封套 / Fanart”改为“图片预览”，分别标注“海报裁切”和“完整封套 / fanart”；尺寸提示应紧邻它描述的图片，并支持点击放大。
3. 将当前 10px 的字段来源按钮提升为可辨识的小型来源标签，至少使用正文辅助字号和稳定点击区域；颜色只用于区分本地、手动与在线来源，不改变现有主操作蓝色。
4. 取消批量模式强制扩窗到固定 1230 的单一策略。队列与图片区可增加 GridSplitter 和合理最小宽度，小屏或高 DPI 环境允许收窄/折叠队列，避免窗口超出工作区。

## 第三优先级：效率增强

- 为搜索、保存、上一部/下一部和切换队列勾选提供可发现的快捷键。
- 为加载中、没有封套、来源失败和未选择影片提供一致的空状态组件，减少仅靠底部状态栏传达的重要信息。
- 保留当前动态“保存全部 / 保存所选”文案、深色下拉框、像素滚动和底部操作状态栏，这些行为已经清晰，无需重做。

## 建议实施顺序

先完成滚动复位、搜索区重排和队列状态区分；再做底部设置折叠、图片标签与来源标签；最后处理可调栏宽和快捷键。每阶段分别验证单片、批量、最小窗口、125%/150% 缩放和四种语言，避免一次大规模 XAML 重排增加回归范围。
