## 当前开发候选（build48，尚未发布）

- 保持 `0.4.0` 预览版本号；build48 不代表正式 1.0，已发布 Preview 2 与 Windows Latest v1.2.3 均不变。
- 回滚按实际文件身份与内容核验所有已提交视频/侧车；先移入同卷隔离目录再检查，外部替换或改动会保留现场并要求恢复，不再删除外部文件。隔离与 NFO 临时文件使用固定长度随机名，合法长文件名不会因临时名扩展而溢出。
- WorkerClient 使用有界异步写队列，请求时限覆盖排队、管道写入与响应；部分帧中断会关闭传输并保留结果未知，不重放保存。
- 保存检查器新增事务恢复记录：核验文件、导出检查结果、明确确认后仅归档日志；归档重核验文件与存活会话，只让相关影片要求重新导入。丢失响应可核实状态，审核草稿保留并可导出数据型参考 JSON。
- 旧格式或证据不足的日志不会自动解除阻止；[手动核查流程](TESTING.md#legacy-transaction-records)要求保留原日志、核对文件和备份、退出全部实例后迁移，并重新导入预览。没有自动重放或盲目确认“已恢复”。
- 图片查看器本地解码失败显示错误与重试；重试重新取得预览，旧读者继续保有必要租约。
- 本机全量门禁通过：Portable 59/745 断言、Swift 97、Worker 103（协议 86、队列 4、保留状态 5、缓存 8），四语 512 键 / 4126 运行时检查。Windows 四项目交叉构建零错误、零警告；交叉构建不代表 Windows 运行时验收。
- 新增故障回归覆盖外部文件替换/修改、管道背压与部分帧、恢复核验/归档响应丢失、取消和草稿保留；真实 Worker 自动回归完成核验、归档、导出草稿、相关基线阻止、重新导入与再次保存。受控故障不代表断电或物理拔盘验收。
- Developer ID、干净 Mac 首次下载/Gatekeeper、真实外接卷/SMB 与持续运行验收仍待完成；签名策略继续遵循 [RELEASING](RELEASING.md)，ad-hoc 包只能作为预览。

## CI 分层与当前验证（2026-10-28）

- 工作流区分 `docs / core / full`。普通既有 C#/Swift 源码编辑采用核心层；保留四语、Portable 54/585、Swift 87、Worker 协议 77、队列原子性与保存期间拒绝移除、保留状态计数/过期令牌/执行幂等/活跃操作、全部 8 项图片缓存生命周期和预算检查，以及 Xcode 源码成员检查。
- 核心 Worker 实际执行 91/94 项；仅 1000 项队列压力、大完成结果字节预算、大 pending-preview 字节预算 3 项转到完整层。完整层仍执行全部 94 项，并增加发布工具/清单、Xcode 平铺模块类型检查、签名 ZIP 与最终解包无 SDK 回归；发布包模式拒绝 core，核心产物只含测试证据。
- 保留状态/缓存/导入/保存预览的压力相关实现、资源/项目/依赖/打包/脚本/workflow、未知文件、新增/删除或缺基线均自动采用 full；`macos-v*` 标签和默认手动验证也强制完整覆盖。手动选择 core 仅验证日常层。Windows 对产品变更保持现有完整自动门禁；具名最终结果明确报告档位，失败或取消不计为通过。

- 同一实现提交 `a50750f` 的云端验收通过：[Mac full](https://github.com/Noredge/JavMetaLite/actions/runs/40743800426) 实际执行 20 分 29 秒，[Mac core](https://github.com/Noredge/JavMetaLite/actions/runs/40747193340) 3 分 53 秒，[Windows 完整门禁](https://github.com/Noredge/JavMetaLite/actions/runs/40743800416) 2 分 36 秒。两档覆盖不同，不是相同工作量的性能对比；full 保留完整签名包和压力验证，未宣称它比旧 full 更快。core 另有约 5 分钟运行器排队，不计入上述执行耗时。
