# macOS 安全约束

实现和回归必须保持下列规则。测试命令见 [TESTING](TESTING.md)，当前验证范围见 [STATUS](STATUS.md)。

| 边界 | 必须保持的行为 |
| --- | --- |
| 审核版本 | 编辑、来源/图片选择和保存都绑定 MovieJob revision；旧响应不能覆盖新审核。修改番号后不得混入旧来源资料。 |
| 保存计划 | Worker 生成不可变 planId；执行前复核 revision、配置、来源/目标指纹。前端不能自行授权写盘。 |
| NFO | round-trip 保留未编辑的 XML、演员子节点和原始值；拒绝 DTD、过大或损坏输入。 |
| 全队列冲突 | 全批次写入前统一预检；未勾选输入、现有视频、共享旁车和样张也受保护。 |
| 文件事务 | 分阶段写入并保留恢复记录；外部修改不被覆盖，无法确认可删除的副本保留并报告。 |
| 视频整理 | Mac 用完整 SHA-256 验证复制；Path.GetPathRoot 不能证明同卷。移除来源前重新验证身份与内容。 |
| 批量/取消 | 已提交前项保留，未开始尾项保持不动；预览取消不发布晚到计划，执行请求不自动重放。 |
| 队列与缓存 | 查看项和勾选集合独立；移除仅释放对应审核状态。通知、缓存、回执和预览有数量/字节边界。 |
| 网页/图片 | 捕获仅在显式导入时发生，限制来源/URL/大小/番号；图片来自已登记候选，旧请求不能替换另一任务。 |
| 本地删除 | 仅通过受协调的系统废纸篓和有效租约操作；失败不回退为永久删除。 |
| 管道/失败 | 断管返回错误，不能以 SIGPIPE 结束客户端；超时不代表保存已失败或允许重试。 |
| 签名/信任 | 包、签名、Developer ID、公证、Gatekeeper 分别验证；只签名策略不隐含系统信任通过。 |

[40 项用例](WINDOWS-CASE-REGRESSION.md)补充交互与文件边界。固定 HTTP、故障注入、APFS 映像及程序化原生 API 测试不能代替物理设备、真人输入法/无障碍、真实站点和长期压力验收。
