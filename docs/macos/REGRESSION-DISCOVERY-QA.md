## 发现确认与取消

正常CmdO→NSOpenPanel→发现sheet；没有用`--import-fixture`绕过确认。初始7/7选中；“选择已识别”替换为3/7；清空后0/7、确认禁用。确认只导入这3项，未知文件未混入。无已识别项窗口默认允许手动加入，识别按钮禁用；取消保持旧草稿、批量1及当前项，再手动取消/选中未知项可加入。标题原生Undo→Redo→Undo执行后回到空草稿；审核revision由真实Worker/Swift集成断言，AX不是revision读数。

两目录原生Command多选：递归发现4项，取消不改队列；关闭递归只发现2个顶层。确认2项后再递归，4条中已有2条禁用，只导入新2条。最终重新签名包又执行四语言发现窗口和7→3精确导入，正常退出。

协议回归同时覆盖单次token、空/重复/外来ID拒绝、容量、实际inode替换/符号链接祖先/删除变化、扫描后新增影片/CD不被带入、加载中取消不留部分任务、TTL受控时钟、释放与回执回收。不是在文件系统持续恶意竞态下的无条件安全保证；保存仍独立复核。
