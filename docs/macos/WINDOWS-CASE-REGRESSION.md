# 40 项跨平台回归用例

来自 Windows 使用案例的长期回归要求。此表保留产品边界，不逐轮累加开发报告；执行入口见 [TESTING](TESTING.md)，已验证/未验证范围见 [STATUS](STATUS.md)。

| 编号 | 检查要求 |
| --- | --- |
| T01 | 网址/点号前缀只移除一次扩展名，保留有效番号与 U/UC/CD 后缀。 |
| T02 | Unicode 长标题、OL 与合法 720 等数字不被误删。 |
| T03 | 方向键只切换查看项；滚动、勾选和语言焦点保持独立。 |
| T04 | 只选择 LibreDMM 时，R18 请求数必须为零。 |
| T05 | 区分限流、超时、未找到和部分成功，只重试已失败的所选来源。 |
| T06 | 未打开的低清完整封套也给出审核提示，保存后不丢失该提示。 |
| T07 | 取消后清理临时文件、释放忙碌状态；清理失败报告真实恢复路径。 |
| T08 | 浅/深色冲突提示、长路径、选中文字和禁用按钮可读。 |
| X01 | 区分权限拒绝与普通 I/O 失败，保留可读项及完整诊断。 |
| X02 | 长路径详情可滚动、全选和复制；查看/关闭不修改审核状态。 |
| X03 | 四语言下的主/次级窗口、工具栏和最小布局不截断关键操作。 |
| X04 | 原生选择多个文件/目录，递归选项和发现确认各自生效。 |
| X05 | 图库/查看器按全局 artworkId 定位，来源筛选不改变候选身份。 |
| X06 | 未逐张打开图片不妨碍按已审核来源生成安全保存计划。 |
| X07 | 兼容旧 movie.nfo、poster/fanart；不同影片不能无条件共享资料。 |
| X08 | 只清理本次成功迁移后的空 extrafanart，统一样张术语。 |
| X09 | 分别测量发现、确认、查询和保存性能；大队列/真实大媒体另行验收。 |
| X10 | 低清或可疑占位图片应待审核；无通用内容识别时不宣称已检测。 |
| P01 | 默认 LibreDMM，并保留有效自定义字段来源配置。 |
| P02 | JAVLibrary 仅用于用户显式网页导入，不混入自动查询。 |
| P03 | R18 离线库/自动数据库下载不属于当前支持功能。 |
| P04 | 发现窗口“选择已识别”替换集合；无番号项仍可手动勾选。 |
| P05 | 筛选、查看项与批量勾选独立；切换筛选不自动改勾选。 |
| P06 | 全选/取消全选统一操作整个队列的复选框，包括筛选隐藏项。 |
| P07 | 分类计数随状态更新；可重叠分类不要求数量相加等于总数。 |
| P08 | 纯数字日期式文件名不自动推断番号，但允许导入后手填。 |
| P09 | a/b、U/UC 等独立版本不自动合并；CD 合并顺序须明确确认。 |
| P10 | 全局来源切换原子应用可用资料/图片，缺字段和共享 URL 按约定处理。 |
| P11 | 原地保留已识别旧旁车命名，新目录使用标准输出命名。 |
| P12 | 低清是审核提示，不禁止合法 NFO 保存，也不假装提升图片质量。 |
| R01 | 覆盖文件名/base 边界、合法数字、FC2、CD、前置数字与负例。 |
| R02 | 按实际文件身份处理大小写、Unicode、硬链接和别名，不全局折叠路径。 |
| R03 | NFO 归属绑定单片或明确 CD 组，避免同目录不同影片污染。 |
| R04 | 第二 CD、外部目标出现或校验不符时回滚，保留来源且不覆盖外部文件。 |
| R05 | 覆盖复制/下载/提交取消和清理失败；物理掉盘/SMB/满盘单独验收。 |
| R06 | 慢图片关闭、取消、重试和晚到响应都不能复活旧预览或污染当前任务。 |
| R07 | 限流冷却、队列等待、失败源重试和再次取消保持当前审核资料。 |
| R08 | 逐窗口检查四语/明暗/最小尺寸/焦点，以及物理 IME、VoiceOver 和手势。 |
| R09 | 极小、损坏、缺失、替换和迟到封套不捏造尺寸或混用旧来源。 |
| R10 | 循环使用后缓存、通知、计划和回执受限；短时 RSS 不证明长期无泄漏。 |

自动化使用合成媒体、受控 HTTP 和临时目录。私有文件名与原始交接材料不上传；真实卷、网站、人机交互和长期使用需单独验收。
