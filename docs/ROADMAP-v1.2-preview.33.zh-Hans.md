# JavMetaLite v1.2.0-preview.33 本地与在线图片分区

## 本轮目标

- 图片查看器将本地图片与在线候选明确分为上下两行。
- 本地海报、Fanart 与 Extra Fanart 使用独立勾选状态，可一次选择多张并批量删除。
- 在线 Extra Fanart 继续使用独立的保存选择与“应用选择”，不受本地删除选择影响。
- 删除前始终显示与主程序视觉一致的深色确认弹窗；批量删除只确认一次。

## 交互规则

1. 图片类型筛选同时作用于两行，但不会混合两种选择含义。
2. “全选本地图片”和“取消选择”只影响当前类型下可见的本地图片。
3. “删除所选”显示当前累计选中的本地图片数量；确认后立即从磁盘删除并刷新当前影片。
4. 在线候选行的选择框只控制保存，关闭查看器不会应用尚未确认的在线选择。
5. 本地文件删除不可撤销，因此单张和多张都必须经过确认。

## 验证门槛

- WPF 回归覆盖两行分区、缩略图选择语义、取消删除、批量删除、在线应用以及深色确认弹窗。
- 完整自动化测试、发布打包与便携包内版本验证全部通过后再提交本地 Git。
