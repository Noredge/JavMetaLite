# JavMetaLite v1.2.0-preview.28 本地 extrafanart 管理与图片分类

状态：已实现，待用户体验验收

基线：`v1.2.0-preview.27`，`43080bb`

更新日期：2026-09-03

## 目标

让图片查看器同时承担“查看”和“管理”职责：用户可以按图片类型浏览在线候选和已有本地图片，修改本地 `extrafanart` 的保留集合，并避免大量图片逐张等待载入。

## 已实现方案

- 载入影片时扫描同目录下的 `extrafanart/`，支持 JPG、JPEG、PNG 与 WEBP，并按文件名尾部数字自然排序。
- 本地剧照逐张校验；单个损坏文件只产生诊断，不影响其余有效图片及影片载入。
- 图片查看器增加“全部 / 海报 / Fanart / Extra Fanart”类型选择，并显示各类型数量。
- 本地与在线 Extra Fanart 合并展示，明确标注来源；两者使用同一套逐张选择、全选、取消全选与应用逻辑。
- 打开查看器后即在后台预载图片：本地优先、最多四路并行、仅缓存当前查看器会话，并与前台切换共享同一载入任务。
- 取消选择本地图片不会立即删除；变化会先出现在保存预览中，确认保存后再由既有备份、回滚与事务提交链路完成同步。
- 未启用 Extra Fanart 输出时，不把本地图片解释为待删除数据；整理或移动影片时会原样迁移这些文件。

## 安全边界

1. 仅把来源影片目录直属的 `extrafanart/` 文件视为可管理的本地剧照。
2. 删除动作必须进入保存计划，并接受源文件指纹校验与事务回滚保护。
3. 关闭图片查看器或按 `Esc` 不应用尚未确认的选择变化。
4. 关闭 Extra Fanart 输出表示“不管理其集合”，已有本地图片必须保留。
5. 在线搜刮刷新 metadata 时，本地剧照候选与当前选择不得被静默覆盖。

## 验收重点

1. 已有本地 `extrafanart` 打开影片后可直接在查看器中看到，并显示“本地”来源。
2. 类型下拉框可独立查看海报、Fanart 与 Extra Fanart；空类型显示明确空状态。
3. 打开查看器后图片在后台逐步就绪，本地图片优先，不再需要逐张停顿等待。
4. 取消一张本地剧照并应用后，保存预览显示移除；取消整个保存操作时文件不得变化。
5. 确认保存后仅移除未选择的本地剧照，保留项与新增在线项组成最终集合。
6. 关闭 Extra Fanart 输出后整理影片，本地 `extrafanart` 仍应逐字节保留。
