# JavMetaLite v1.2.0-preview.41 安全替换与整套图片来源

## 本轮目标

- 将“替换本地 Extra Fanart”从永久删除许可改为当前影片、当前番号、当前在线搜索结果驱动的条件行为。
- 在自定义多来源规则中提供可选的高清整套图片来源，同时保持默认推荐多来源搜索不变。
- 补齐单片移除入口，并修复队列方向键首次切换后丢失焦点的问题。

## 保存安全边界

- 只有当前番号的在线搜索实际取得至少一张在线样张时，“替换本地 Extra Fanart”才会生效。
- 未搜索、搜索失败或没有在线样张时，保存计划将现有本地 Extra Fanart 全部标记为保持不变，`Ctrl+S` 也不能绕过该限制。
- 修改番号或载入另一部影片会清除此前的替换资格；单片与批量任务各自保存独立状态。
- 已取得在线样张后，用户若明确取消全部在线选择并继续勾选替换，保存预览会列出清空本地集合的实际删除动作。

## 自定义高清整套图片

- “较高清图片（整套）”只存在于自定义多来源的图片规则，不改变“多来源搜索（推荐）”的默认行为。
- 两个来源都成功时并行读取完整横板封套的真实像素尺寸，并以宽乘高选择较高分辨率；同尺寸固定优先 LibreDMM。
- 选定来源同时提供完整封套、由该封套生成的海报裁剪，以及默认在线 Extra Fanart，避免自动结果混用来源。
- 一个来源失败时直接使用另一个；只有一个有效图片来源时不额外下载图片进行比较。
- 图片查看器继续保留两边候选，用户仍可人工检查和调整。

## 单片与键盘交互

- 搜索栏标签简化为“来源”。
- 单片图片卡增加“移除影片”，只清理当前工作区，不删除磁盘上的影片或旁车文件，也不弹出破坏性确认。
- 队列第一次用方向键切换并完成图片载入后，焦点会恢复到新项目；后续 `↑/↓` 可以继续移动。
- 方向键只在队列内部且没有修饰键时处理，文本框、下拉框和全局键盘行为不受影响，也不恢复 `Alt+↑/↓`。

## 验证门槛

- 文件事务回归必须证明未搜索时零删除、零改写并保持本地 Extra Fanart 哈希不变。
- Core 回归覆盖高低分辨率、相同分辨率、单来源、图片读取失败及整套来源一致性。
- 批量搜索验证每部影片独立解析高清图片来源。
- WPF 自动检查覆盖四语言标签、自定义规则第三选项、连续方向键导航和单片移除不删文件。
