# JavMetaLite v1.2.0-preview.27 可选择的 extrafanart 查看器

状态：已实现，待用户体验验收

基线：`v1.2.0-preview.26`，`5831cd7`

更新日期：2026-09-03

## 目标

让图片查看器覆盖实际保存链路中的全部图片，同时允许用户决定哪些样品图应写入 `extrafanart/`，而不把海报、fanart 与样品图的选择逻辑混在一起。

## 已实现方案

- 查看顺序统一为：海报裁切、完整封套 / fanart、样品图 / extrafanart 1…N。
- 海报和 fanart 继续由主界面的图片来源按钮控制，不在查看器中重复提供另一套来源选择。
- 样品图进入时才下载；未浏览的图片不会因为打开查看器而全部下载。
- 每张样品图提供“保存这张样品图”复选框。
- 提供“全选样品图”“取消全选”和实时选择数量。
- 只有点击“应用选择”才修改当前影片；普通关闭或 `Esc` 不改变保存列表。
- 应用后的 `ScreenshotUrls` 直接供现有输出服务使用，因此启用 extrafanart 输出时只下载并写入选中的图片。
- 可用图片从保留的来源结果重建；取消某张后再次打开查看器仍能重新选择，无需重新搜索 metadata。

## 验收重点

1. 有样品图时，海报与 fanart 后面应显示完整样品图序列。
2. 打开查看器不应一次下载全部样品图；切换到某张时才出现载入状态。
3. 单张勾选、全选和取消全选应立即更新选择数量。
4. 关闭或按 `Esc` 后不应应用尚未确认的变化。
5. 点击“应用选择”后，保存预览中的 `extrafanart` 数量与选择一致。
6. 取消过的图片再次打开查看器仍可重新选择。
