日期：2026-09-04。未提交、未推送、未打标签、未对外发布；保留原有未提交修改、旧便携包和 SDK/依赖缓存。

## 修复范围

- R18 API 共享单路调度，默认请求起点至少间隔 1 秒。该间隔是本项目的保守策略，不是对网站官方配额的承诺。
- HTTP 429 优先于 HTML/未收录判断；尊重 Retry-After 的秒数或日期（考虑响应 Date），并至少使用共享的 5/10/20…秒退避。每次最多自动重试同一 URL 两次，不立即改用备用地址轰炸网站。
- 剩余冷却超过 30 秒时保留可重试的限流结果，让其他来源和队列继续；短冷却/排队可取消，网络请求的 10 秒默认超时从实际请求开始计算。
- 批量汇总区分完整、部分失败、全部失败、取消和未开始。部分失败进入“问题”筛选并显示橙色状态，429 提供本地化说明；不恢复主界面的重复顶部提示。
- 批量底部“重试所选失败来源”只处理已选影片的失败来源，复用成功结果。恢复后重选自动回退的首选字段/图片，保留明确审核过的字段来源、手动值/空值、演员图片和图片/样张选择。加载本地样张不算人工锁定来源；取消重试保留原资料及失败记录。
