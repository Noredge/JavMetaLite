# JavMetaLite v1.2.0-preview.39 来源操作间距

## 本轮目标

- 增加自定义多来源齿轮与下拉箭头之间的视觉留白。
- 保持来源名称的可用宽度，不因留白增加而截断英文或其他语言文字。
- 保持来源选择器的外部尺寸、位置和响应式布局不变。

## 视觉调整

- 齿轮按钮向左移动 3 个独立像素，与下拉箭头之间形成更清晰的间隔。
- 分隔线同步左移，保持分隔线与齿轮之间的原有节奏。
- 左侧内边距减少 3 像素，右侧保留区增加 3 像素，文本可用宽度总量不变。

## 验证门槛

- 渲染后的齿轮右边缘与下拉箭头左边缘至少保留 3 个独立像素。
- 四种界面语言的来源名称仍能在最小窗口中正常显示。
- 单片与批量模式切换来源时，来源选择器的行列、宽度和坐标保持不变。
