# JavMetaLite v1.2.0-preview.21 手动网页查询可靠性修复

状态：已实现，待用户体验验收

基线：`v1.2.0-preview.20`，`d7e4b73`

更新日期：2026-09-03

## 目标

修复 R18.dev 手动网页查询无法自动定位部分实际存在影片的问题，并让用户明确确认导入的网页资料立即成为当前审核内容。

## 已实现规则

- R18.dev 目标没有真实详情页时，先复用自动来源查询解析网站的权威 `content_id`，再打开普通影片详情页；例如 `ABF-193` 会定位到 `118abf193`。
- 预解析只决定浏览器打开地址，不会加入候选或修改当前资料；自动解析失败时仍打开已预填番号的网站搜索，保留纯手动路径。
- 只有用户在正确详情页点击“读取当前影片”后才导入资料。
- 网页中的全部非空字段和可用封套立即成为当前选择；网页缺失字段继续沿用导入前的值。
- 本地 NFO、其他搜刮来源及手动输入候选继续保留，可在审核界面逐字段或按封套来源切回。

## 验收门槛

- 离线回归验证 `ABF-193 → 118abf193` 的详情页路由，以及已解析目标不会重复请求来源。
- 离线回归验证网页非空字段和封套优先、本地缺失字段保留、旧候选可切回、错误番号被拒绝。
- 完整自动化门禁通过后生成 `v1.2.0-preview.21` 便携体验包并提交本地 Git，不推送远端。
