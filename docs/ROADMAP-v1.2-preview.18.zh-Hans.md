# JavMetaLite v1.2.0-preview.18 R18.dev 未收录回退路线

状态：已实现，待用户体验验收

基线：`v1.2.0-preview.17`，`16053d1`

更新日期：2026-09-03

## 目标

当 R18.dev 没有对应番号时，为用户提供可继续操作的手动查询路径，并避免把网站维护或网络故障误报为“未收录”。

## 已实现规则

- R18.dev 返回明确 HTTP 404 时，浏览器顶部显示黄色非阻塞提示：“可能尚未收录”。
- 提示包含当前请求番号；浏览器随后自动返回 R18.dev 官网首页，并把原番号预填到网站搜索框中，不自动提交。
- 网站 HTTP 4xx/5xx、导航失败，或详情地址没有可读取的影片结构时，显示独立的红色“暂时无法访问”状态。
- 普通首页或其他非详情页显示“请手动查询”，不弹出阻塞窗口。
- “读取当前影片”默认禁用；仅当官方可信域名、正常 `id=...` 详情地址及 `#video-info` 结构同时成立时启用。
- 既有候选、字段选择和封套不会因未收录、维护或手动查询而被清除，也不会触发保存。

## 状态判定

| 情况 | 显示 | 后续动作 |
| --- | --- | --- |
| HTTP 404 | 黄色“可能尚未收录” | 返回首页并预填原番号 |
| HTTP 4xx/5xx 或导航失败 | 红色“暂时无法访问” | 保留页面，允许稍后重试或切换来源 |
| 官网首页或其他非详情页 | 黄色“请手动查询” | 预填原番号，等待用户修改/提交 |
| 有效官方详情页 | 隐藏提示 | 启用“读取当前影片” |

## 验收门槛

- Core 回归覆盖未收录、维护、导航失败、有效详情、官网首页和相似域名。
- WPF 回归覆盖提示文本、黄色/红色区分、读取按钮门禁及最小窗口布局。
- 完整自动化门禁通过后生成 `v1.2.0-preview.18` 便携体验包并提交本地 Git，不推送远端。
