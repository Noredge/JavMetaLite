# JavMetaLite v1.2.0-preview.25 最小窗口响应式布局

状态：已实现，待用户体验验收

基线：`v1.2.0-preview.24`，`565b093`

更新日期：2026-09-03

## 问题判断

preview.24 虽然把自动来源移回搜索工具栏，但使用 `WrapPanel` 后，控件会按剩余宽度任意换行。在最小批量窗口中，队列和图片区占用固定宽度，资料区只剩约 310px，因此搜索区会出现不可预测的两行或三行排列。

## 本轮方案

- 不再使用自动换行面板，搜索区改为明确控制的响应式网格。
- 空间充足时保持单行：番号、输入框、搜索资料、手动网页查询、自动来源和编辑规则依次排列。
- 空间不足时固定为两行：
  - 第一行：番号、输入框、搜索资料。
  - 第二行：手动网页查询、自动来源、编辑规则。
- 紧凑布局只隐藏重复的“自动来源”文字标签，不隐藏来源选择器、来源策略提示或编辑规则入口。
- 批量模式默认队列宽度由 240px 调整为 220px，图片区由 300px 调整为 250px，把最小窗口中的可用空间优先留给资料审核。
- 队列和图片区的拖动分隔线继续保留，用户手动调整后的宽度不会被普通队列刷新重置。

## 验收重点

1. 普通宽度下，搜索工具栏保持完整单行，不出现自动换行。
2. 将批量窗口缩到 930px，搜索区只出现整齐的两行，不应出现第三行或孤立按钮。
3. 紧凑布局中，手动网页查询、自动来源和编辑规则保持在同一行。
4. 在自定义多来源与其他来源间切换，布局应稳定且控件不越界。
5. 拖动队列或图片区分隔线后执行普通队列操作，宽度不应被重置。
