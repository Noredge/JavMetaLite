## 1.2 的交付范围

1. **单片与批量审核工作台**：拖入文件／文件夹、递归发现、将 CD1/CD2 分组为一部影片、独立逐片状态、统一批量验证与保存；不要求逐部打开预览。
2. **明确的来源选择**：LibreDMM 默认推荐；R18.dev 按需使用；自定义多来源保留逐字段规则和可选高分辨率整套图片比较；JAVLibrary 仅手动网页查询。批量与单片遵守同一来源选择。
3. **一致的图片交互**：主界面进入查看器默认“全部图片”并定位到点击项；本地与当前来源的在线候选分行；来源与样张选择联动，应用后生效；本地图片删除在查看器内确认后立即执行。
4. **安全保存**：变更预览、已有资料覆盖确认、无搜索时不清空本地 Extra Fanart、替换下载失败保护、本地样张读取失败阻止提交、跨影片输出冲突预检、跨卷校验、失败恢复与保留现场。
5. **流畅性与可靠性**：大队列通知／统计／导入优化，有界预览缓存、方向键焦点修复、每部最多 3 张样张并发下载、低分辨率审核提示、文件短暂占用重试。
6. **四语言与界面一致性**：统一搜索栏、像素滚动、折叠图片列表／保存设置、深色确认框和必要键盘交互。

不把 R18 离线库、Jellyfin 插件、持久化队列、跨影片并行保存或大规模重构加入本次收尾。

## 已知边界与风险说明

- **R18 慢不等于失败**：限流或线路会影响时间；等待可取消。默认使用 LibreDMM，需要英文资料或图片比较时再用 R18／自定义。没有离线库，也不承诺搜索速度。
- **低分辨率是尺寸提示**：只看完整封套／fanart 的原始尺寸；最长边 <400 px 或横图宽度 <600 px。不能识别放大后模糊的图片；无法测量表示未知。未读取过的在线图片检查会增加请求。
- **预览与输出分离**：批量保存不为未查看影片额外加载预览；“预览未加载”不是下载失败。预览缓存有上限，退出后不保留队列。
- **恢复是尽力而为**：短暂共享冲突有限重试，但权限、磁盘故障、持续锁定或断电仍可能阻止恢复。不承诺任意故障下自动恢复；保留目录中的旧备份不能自动清理。
- **少量图片候选 404**：存在回退 URL 并最终成功时，不等同影片搜索／保存失败。本次不扩大为重写来源探测；真正无有效图片或资料失败仍须按提示处理。
- **真实性能需谨慎解读**：离线固定延迟样张测试的加速不能推广为线上倍速；相同 71 部的两次真实保存约 184.5／187.7 秒，不是受控 A/B。本次不承诺所有批次更快。
- **人工环境仍待验证**：WebView2、实际网站、Jellyfin 展示、不同 DPI／长路径、真实跨盘／UNC、大文件取消、外部程序占用，不由离线自动化完整覆盖。审查发现的默认宽度下英文／日文遮挡已纳入 preview.56 小布局修复和实际文字测量；96 DPI 渲染不替代各系统缩放下的人工验收。
