# preview.45：批量搜索遵守所选来源（内部审核）

日期：2026-09-04。未提交、未推送、未打标签、未对外发布；保留原有未提交修改、旧便携包和 SDK/依赖缓存。

## 修复范围

- 单片和批量使用同一套来源规则：LibreDMM 只请求 LibreDMM；R18.dev 只请求 R18；自动多来源和自定义多来源请求两者。只有自定义模式应用自定义字段/图片规则。
- 批量开始时固定本轮来源及自定义规则，避免后续界面状态改变影响剩余影片；按钮说明和运行提示显示请求来源。新的一次单来源搜索成功即为完整成功，不因未请求另一来源而显示部分失败。
- 自动来源列表和自动重试移除 JAVLibrary；保留当前影片的手动网页查询、解析、评分和来源追踪。旧设置中的 `javlibrary` 转为手动模式，不静默开启其他自动来源。
- 手动模式禁用队列自动搜索，入口及协调器也有保护；不会批量打开网页。手动导入只影响当前影片。
- “重试所选失败来源”只重试当前来源范围内的失败项。范围外的既有结果和失败记录保留，但不发送请求；例如切到 LibreDMM 后不会偷偷重试 R18。历史失败记录不会被伪装成成功。
